# Security

Conflux is an early-stage project without accounts or document-level permissions. Anyone who can reach the sync server can read and edit its documents. Origin checks help prevent cross-site browser connections but are not authentication. Do not expose an instance to the public internet or use it for sensitive information.

If you find a vulnerability, do not disclose it in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled, or contact the repository maintainer privately.

There are no supported released versions with a security update policy yet.
